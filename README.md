# Refund Desk

オンラインスクールの中途解約に伴う返金額を、契約情報・期間・休会日数から自動計算するWebアプリです。

## 主な機能

- 休会日数を除いた実消化日数の自動計算
- 月次ベースと日次ベースの返金額算出
- 「月次の半額 → 月次 → 日次」の3段階提示
- 違約金の100円未満切り捨て
- 返金額がマイナスの場合の不足額表示
- 試算結果のワンクリックコピー
- スマートフォン対応

## 計算ルール

```
返金不可能額 = min(50,000円, 契約残額 × 20%) + 入会金
月次換算額 = (契約金額 - 入会金) ÷ 契約月数
返金額（月次） = 支払済み総額 - (返金不可能額 + 月次換算額 × 経過月数)
1日あたり受講料 = (契約金額 - 返金不可能額) ÷ 契約日数
違約金 = 返金不可能額 + 1日あたり受講料 × 受講日数（100円未満切り捨て）
返金額（日次） = 支払済み総額 - 違約金
```

## 開発

Node.js 22.13以上が必要です。

```bash
npm install
npm run dev
npm run build
```
