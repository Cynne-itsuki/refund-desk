# VISION 返金額算出シュミレーター

オンラインスクールの中途解約に伴う返金額を、契約情報・期間・休会日数から自動計算するWebアプリです。

**公開版:** https://refund-desk.copperpony10.chatgpt.site

## 主な機能

- ミニマム（3ヶ月・50万円）、アドバンス（6ヶ月・90万円）、ロイヤル（9ヶ月・120万円）、パーフェクト（12ヶ月・200万円）の参考額を自動入力し、契約金額は自由に変更可能
- 入会金40万円は入力欄を設けず、契約金額からサービス利用料を自動算出
- 契約条件・支払会社・計算過程・対応フローをまとめた共有用算出書を自動生成
- 休会日数を除いた実消化日数の自動計算
- 月次ベースと日次ベースの返金額算出
- 「月次の半額 → 月次 → 日次」の3段階提示
- 受付から返金完了までの8段階対応ナビ
- 各タイミングで送るメッセージ文面の自動生成・コピー
- 合意額を選択し、合意書・返金完了文面へ反映
- 違約金の100円未満切り捨て
- 返金額がマイナスの場合の不足額表示
- 試算結果のワンクリックコピー
- スマートフォン対応

## 計算ルール

```
返金不可能額 = min(50,000円, 契約残額 × 20%) + 入会金（40万円）
サービス利用料 = 契約金額 - 入会金
月次換算額 = サービス利用料 ÷ 契約月数
返金額（月次） = 支払済み総額 - (返金不可能額 + 月次換算額 × 経過月数)
1日あたり受講料 = (契約金額 - 返金不可能額) ÷ 契約日数
違約金 = 返金不可能額 + 1日あたり受講料 × 受講日数（100円未満切り捨て）
返金額（日次） = 支払済み総額 - 違約金
```

```bash
pnpm install
pnpm dev
pnpm build
```
